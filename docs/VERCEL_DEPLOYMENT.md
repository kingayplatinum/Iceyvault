Import kingayplatinum/Iceyvault into Vercel, framework Next.js, production branch main. Build: npm run build. Install: npm install. Initially deploy without Supabase in preview mode. Later add NEXT_PUBLIC_SUPABASE_URL and NEXT_PUBLIC_SUPABASE_ANON_KEY. All service-role, payment and provider secrets must be server-side only. Vercel auto-deploys after the project is imported and connected to GitHub; user will create the Vercel project.
