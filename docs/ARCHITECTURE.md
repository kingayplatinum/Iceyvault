Core domains: identity, NGN wallet/ledger, payment reconciliation, service catalogue, supplier adapters, fulfilment orders, rentals, inbound messages and audit/operations. Catalogue offers are country + service/channel + offer kind + number class + term + features + supplier + verified stock + wholesale cost + NGN retail quote + timestamp. WhatsApp/Telegram labels describe explicitly supported compatibility, not official platform affiliation. TextPlus/TextNow/Google Voice must remain disabled until written distribution agreements exist. Provider request timeouts enter an indeterminate state and must be reconciled before retry. Payment webhooks require signature and independent gateway verification. Wallet changes are server-owned, atomic and idempotent. Durable worker required for polling, retries and expiry.
